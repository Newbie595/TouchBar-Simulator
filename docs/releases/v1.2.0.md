# v1.2.0 预发布：实体触控栏镜像与唤醒恢复

这个版本供 Apple 芯片与 Intel Mac 测试。下载下方的 `TouchBar-Simulator-universal.dmg`，打开后将 `TouchBar Simulator (Newbie595).app` 拖入“应用程序”文件夹。

## 本次改进

- 有实体 Touch Bar 的 Mac 直接读取实体显示流，减少与键盘上内容不一致的情况；没有实体栏的 Mac 保留原有模拟路径。
- 合盖、屏幕熄灭、唤醒和解锁后重建显示流；全黑首帧会先快速重试，之后低频持续重连。
- 解锁后再次延迟重连，处理首帧仍停留在锁屏触控栏布局的情况。
- 窗口右键菜单增加“重新连接 Touch Bar”，恢复异常时不必退出程序。
- 状态栏菜单增加浮动、置顶、置底、边距、不透明度、跨桌面显示、靠边自动隐藏、登录启动和手动重连。
- 修正窗口缩放后的点击坐标，并提供 Apple 芯片与 Intel 通用 DMG。

## 已完成的验证

- 在 macOS 15.8.1、2020 款 M1 MacBook Pro 上完成一次真实合盖唤醒测试；解锁后窗口重新收到有效画面。
- 授予“辅助功能”权限后，窗口点击可传到实体触控栏。
- 本机和 GitHub Actions 构建通过；应用与 XPC 服务均包含 `arm64` 和 `x86_64`。

## 安装与限制

本版本使用临时签名，尚未经过 Apple Developer ID 签名与公证。若系统阻止打开，请确认文件来自此仓库，再按 macOS 的“隐私与安全性”提示操作。窗口显示不需要“辅助功能”权限；从窗口点击实体触控栏需要在“系统设置 → 隐私与安全性 → 辅助功能”中允许**这份 fork 应用**。

它与 Sindre Sorhus 的 `Touch Bar Simulator` 是两款不同应用，可以根据名称和 Bundle ID 区分。窗口菜单功能在本 fork 中重新实现，设置不会自动从另一款软件迁移。测试版重新构建后签名可能变化；若系统设置显示已授权但点击无效，请移除旧的 `TouchBar Simulator`（无空格）授权条目，再添加当前安装的应用。

本项目使用 macOS 私有触控栏接口。当前只完成了上述机器上的一次合盖唤醒验证，欢迎继续测试多轮休眠及不同前台应用；遇到问题时请附上 macOS 版本、触发步骤、窗口截图及实体触控栏快照。
